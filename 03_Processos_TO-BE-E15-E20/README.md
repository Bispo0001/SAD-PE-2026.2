
# Processos TO-BE - E15 a E20

Esta pasta reúne os processos propostos do SAD-PE, representados em BPMN
TO-BE para o Campus Aracaju do IFS.

## Módulos

- [M1 - Identificação de Risco](./M1_Risco/README.md): identifica riscos,
  valida dados e cria ou atualiza casos no SAD-PE.
- [M2 - Priorização](./M2_Priorizacao/README.md): consolida dados, calcula
  prioridades e organiza a fila de atendimento.
- [M3 - Intervenção](./M3_Intervencao/README.md): registra, planeja, executa
  e reavalia as intervenções pedagógicas.
- [M4 - Painel Analítico](./M4_Painel/README.md): consolida indicadores de
  permanência e apoia decisões institucionais.

## Organização

Cada módulo possui uma pasta própria com o PDF BPMN TO-BE e seu README
específico. Os arquivos desta etapa registram propostas sujeitas à validação
das regras institucionais, do ROD e das áreas responsáveis.
