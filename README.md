# MVP SAD - Estratégia BPM
 
## Sobre o projeto
 
Este repositório centraliza os artefatos do projeto MVP SAD, incluindo processos BPMN, modelos de dados, contratos de interface, modelos de decisão, protótipos e documentação final.
 
## Objetivo
 
Estabelecer uma estrutura padronizada para elaboração, armazenamento, revisão, aprovação e rastreabilidade dos documentos do projeto.
 
## Estrutura do repositório
 
- `01_Processos_BPMN`: processos AS-IS e TO-BE;
- `02_Modelo_ER`: modelos e diagramas de dados;
- `03_Contratos_Interface`: contratos de integração entre módulos;
- `04_Modelos_Decisao`: regras e modelos de decisão;
- `05_Prototipos_UI`: protótipos e fluxos de interface;
- `06_Documentacao_Final`: documentos consolidados e aprovados;
- `GUIA_NOMENCLATURA.md`: regras para nomes e versões dos arquivos.
 
## Regras principais
 
1. Todo documento deve seguir o guia de nomenclatura;
2. Toda alteração deve possuir uma mensagem de commit;
3. Versões em elaboração deverão iniciar em `v0.1`;
4. A primeira versão aprovada deverá ser identificada como `v1.0`;
5. Alterações significativas deverão gerar uma nova versão principal;
6. Documentos internos não deverão ser compartilhados fora da equipe.
 
## Padrões de arquivos
 
Exemplos:
 
M1_BPMN_TO-BE_v1.2.pdf
 
Contrato_M1_M2_v2.0.json
 
M1_Modelo_ER_Logico_v1.0.pdf
 
MVP_SAD_Relatorio_Final_v1.0.pdf
